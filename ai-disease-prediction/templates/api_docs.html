REST API

JSON over HTTP. The machine-readable OpenAPI 3 description is at /api/openapi.json. Predictions are educational estimates, not diagnoses.

POST /predict

Predict from symptoms. Send Content-Type: application/json. age and gender are optional and only used if the model was trained with them. Add "save": false to skip saving to history.

curl -X POST {{ request.url_root }}predict \
  -H "Content-Type: application/json" \
  -d '{"symptoms": ["fever", "cough", "fatigue"], "age": 34, "gender": "female"}'
{
  "prediction": "Example Disease",
  "confidence": 0.82,
  "top_predictions": [{"disease": "Example Disease", "probability": 0.82}],
  "selected_symptoms": ["fever", "cough", "fatigue"],
  "explanation": [{"symptom": "fever", "label": "Fever", "effect": 0.31}],
  "low_confidence": false,
  "model_version": "20260101-120000",
  "trained_on_synthetic_data": true,
  "disclaimer": "...",
  "id": 12, "result_url": "/result/12"
}

Errors return {"error": "message"} with status 400 (invalid input), 413 (body too large) or 503 (model not trained).

GET /api/symptoms

List valid symptom identifiers and labels.

GET /api/model

Model name, version, training time, number of diseases and symptoms.

GET /health

Returns {"status": "ok", "model_loaded": true|false}.
